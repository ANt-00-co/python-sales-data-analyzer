# Python Sales Data Analyzer

A Python program that analyzes sales data from a CSV file and creates a summary report.

## What it does

- Reads sales records from `sales_data.csv`
- Calculates total revenue
- Finds the best-selling product by units sold
- Finds the product with the highest revenue
- Creates an Excel-friendly report named `sales_summary.csv`

## How to run

1. Put sales records in `sales_data.csv`.
2. Open `sales_analyzer.py` in Python IDLE.
3. Click **Run → Run Module** or press `F5`.
4. Open `sales_summary.csv` in Excel or Google Sheets.

## Technologies used

- Python
- CSV module
- defaultdict
